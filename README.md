# ⚡️ OnlyFits — Тренировки и Питание в Telegram (Бесплатный аналог App Store Onlyfits)

Полноценный карманный фитнес-клуб и умный дневник питания в формате **Telegram Mini App** без платных подписок. 

---

## 🌟 Ключевые возможности (как в Onlyfits Pro из App Store):

### 1. 🏋️ Дневник тренировок и Программы:
- **Готовые программы тренировок:** для зала и дома (3-дневный сплит: Грудь/Трицепс, Спина/Бицепс, Ноги/Плечи).
- **Интерактивный режим активной тренировки:**
  - Удобная запись подходов (Вес кг × Повторения) с историей предыдущих показателей.
  - Встроенный **Таймер отдыха между подходами** (обратный отсчет 90с с виброоткликом, кнопки `+30с` и `Пропустить`).
  - Подсчет суммарного тоннажа и длительности тренировки.
- **База упражнений с техникой выполнения:** подробные инструкции и советы по группам мышц (Грудь, Спина, Ноги, Плечи, Руки).

### 2. 🥗 Питание и КБЖУ:
- Персональный расчет калорий и БЖУ (белки, жиры, углеводы) по формуле Миффлина-Сан Жеора под вашу цель (похудение, набор массы, рельеф).
- Дневник приемов пищи (Завтрак, Обед, Ужин, Перекус).
- **📸 ИИ-сканер тарелки:** возможность отправить фото блюда (в приложении или прямо в чат с ботом) для мгновенного определения КБЖУ!
- Трекер выпитой воды (с быстрым добавлением по 250 мл).

### 3. 📈 Тело и Прогресс:
- Запись и график изменения веса.
- Замеры ключевых параметров тела (талия, грудь, бедра, бицепс).
- Счетчик серии тренировочных дней (Streak 🔥).

## 🚀 Пошаговый запуск на Render.com

### Шаг 1: Зафиксируйте и отправьте код на GitHub
```bash
git add .
git commit -m "Switch to OnlyFits: Workout and Nutrition Telegram Mini App"
git push origin main
```

---

### Шаг 2: Создайте Web Service на Render
1. Зайдите на [dashboard.render.com](https://dashboard.render.com).
2. Нажмите **«New +» ➔ «Web Service»**.
3. Выберите ваш репозиторий `tg-app`.
4. Параметры:
   - **Name**: `onlyfits-tg`
   - **Language**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn --workers 1 --threads 4 --timeout 60 main:app`
   - **Instance Type**: `Free`
5. В **Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` = ваш токен от `@BotFather`
   *(URL сайта Render определит автоматически через `RENDER_EXTERNAL_URL`)*
6. Нажмите **«Deploy Web Service»**.

---

### Шаг 3: Настройте кнопку в @BotFather
1. Откройте `@BotFather` в Telegram.
2. Отправьте команду `/mybots` и выберите вашего бота.
3. Перейдите в **Bot Settings** ➔ **Menu Button** ➔ **Configure menu button**.
4. Введите полученный URL с Render (например, `https://onlyfits-tg.onrender.com`).
5. Название кнопки: `⚡️ OnlyFits`.
6. Готово! Теперь бот и Mini App работают в Telegram.
